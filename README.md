# MYTHRON

A cybersecurity-focused AI red-team agent for authorized security assessments.

## Vision

MYTHRON is not a chatbot with a security prompt. It is an end-to-end cybersecurity AI system: reasoning core + agent orchestrator + memory + browser agent + dynamic code engine + sandbox + security capabilities + verification + reporting + evaluation.

## Authorized Use Only

- Authorized security teams
- Organizations testing their own systems
- Explicitly authorized penetration tests
- Controlled security laboratories
- Approved enterprise security assessments

The system must not treat arbitrary Internet assets as automatically authorized.

## Current Phase

Phase 8 — Evidence + Reporting. See PROJECT_STATUS.md.

## Tech Stack

- Language: Python 3.14
- OS: Kali GNU/Linux Rolling (2026.3)
- AI Core: API-based reasoning (local inference not viable — see ARCHITECTURE.md)
- Storage: Local filesystem; database planned for a later phase
